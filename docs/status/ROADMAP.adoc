== Intent (recorded 2026-09-02, owner ruling)

This investigation is meant to handle orbits around Riemann spheres, taking the line from a flat field to motion around a compactified plane. The name is a joke on Спутник-1: Планер is the Russian word for a glider or sailplane (not a powered plane, which would be самолёт), so Планер-1 reads as "Glider-1", the orbital one. The slug `planer-1` is the transliteration; it is not "planar", which is precisely what a Riemann sphere is not. How the orbits are represented on the field, and what gates they must pass, is not yet specified.
